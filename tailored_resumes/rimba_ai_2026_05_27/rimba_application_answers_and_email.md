## Form Answer 2: Tell Us About A Technical Project You’re Proud Of

One project I’m proud of is Hyoka, an AI-agent reliability control plane I built to make agent behavior observable, testable, and safer to promote.

The system has a FastAPI backend, PostgreSQL/SQLite storage through SQLAlchemy/Alembic, worker-owned eval/replay execution, trace ingestion, release gates, signed manifests, API keys, audit logs, and a Next.js dashboard. The core idea is that AI systems should not just produce outputs; their decisions should be traceable, replayable, and gated before changes are promoted.

I’m proud of it because it forced me to think beyond the demo layer. I had to design database models, API boundaries, worker leases, artifact integrity, dashboard views, and failure handling. It is close to the kind of work I want to do professionally: building production systems where workflows, reliability, and auditability matter.

I can show a live demo of importing traces, running validation, viewing results, and checking the gate/audit trail.
