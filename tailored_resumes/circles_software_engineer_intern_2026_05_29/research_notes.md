# Circles Research Notes

Role source: user-provided hiring poster.

Poster requirements:
- Intern - Software Engineer, full-time.
- Bangalore.
- Duration: 1 year.
- Staff referrals for final-year students pursuing software engineering or related degree.
- Looking for proficiency in at least one modern programming language, at least one SQL and one NoSQL database, data structures, analytical problem solving, cloud and network knowledge, teamwork, and willingness to learn.

Company research:
- Circles is a global telco technology/SaaS company founded in 2014.
- The company says it helps telco operators launch or refresh digital brands and transform into techcos.
- Partners/customers mentioned publicly include KDDI, e&, AT&T, and Telkomsel.
- Circles describes its platform as a cloud-native, full-stack telco operating system / CXOS.
- Product areas include digital telco brands, OSS/BSS integration, Open API platform, OTT integrations, digital advisory/support services, AI-native telco direction, and customer-experience-focused telco operations.

Resume positioning:
- Make this backend/platform heavy, not AI-heavy.
- Lead projects:
  - Seaweed for Go, PostgreSQL, Redis, concurrency, DSA/ranking, Kubernetes, async workers.
  - Postificus for queues, retries, DLQs, circuit breakers, Prometheus, PostgreSQL/Redis/RabbitMQ.
  - Swish for customer-support workflow/state modeling, relevant to telco customer experience and support operations.
  - Hyoka for observable backend workflows, trace ingestion, worker leases, API keys, audit logs.
- Experience:
  - Bentham AI for backend automation, public API lookups, retry/session recovery, Docker, Cloud Run, GitHub Actions.
  - GSoC for Python, large-data processing, async/parallel optimization, debugging correctness.
