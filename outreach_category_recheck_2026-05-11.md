# Outreach Category Recheck

Research date: 2026-05-11

Goal: re-verify whether each company still deserves one of these outreach modes:

- `PoW + cold mail`: build or package a concrete proof-of-work before outreach.
- `Tailored resume + cold mail`: no bespoke PoW first; use a tailored resume, a tight technical note, and optionally an existing relevant project.
- `Cold/formal only`: do not spend deep prep time unless a specific role or reply appears.

Method: rechecked public company pages, careers pages, official blogs/press, YC/job pages where available, recent news, and selected recent public discussion/search signals. Category decisions are strategic inferences from hiring signal, company maturity, role surface, and expected marginal return on custom work.

## Category Changes Since The Previous Notes

- `Redis`, `ManageEngine`, `StackGen`, and `Miniorange` remain upgraded from cold-only to `Tailored resume + cold mail` because current public product/careers signals are stronger than the older tier suggested.
- `Scalify` moves from pure cold-only to `Tailored resume + cold mail` only if you are targeting frontend/product/web-platform work; otherwise treat it as cold-only for backend/infra/AI.
- `Atlan` is added as `Tailored resume + project walkthrough prep`. Do not build a custom clone-style PoW; prepare a strong metadata/context-layer story and have code/demos ready.
- `Blip AI` is added as `Tailored resume + cold mail, conditional`. It has a real small-team AI dictation product and founder visibility, but the hiring signal is thin and public evidence points to cloud/API-based models rather than a defensible on-device-model angle.
- `Bloom / Plura` is ambiguous in search because several companies use similar names. For the original `Bloom Community -> Plura` target, use `heyplura.com` / YC Plura sources, not unrelated `plura.ai` or `trybloom.ai` results.

## Resume/Message Notes That Matter

- For `PoW + cold mail`, send the artifact link in the first 2 lines. The artifact should be adjacent to the company's technical problem, not a clone.
- For `Tailored resume + cold mail`, use one targeted project already in your inventory and rewrite only the bullets. Do not build a new project first.
- For `Cold/formal only`, cap effort at 10-15 minutes per company unless a specific role appears.
- For Atlan, bring project code/demos to the interview. Their process explicitly says they will discuss personal or academic projects.
- For database/infra companies, generic AI wording is weak. Use systems terms: latency, throughput, correctness, failure modes, storage, indexes, replication, observability, and cost.
- For AI-security companies, lead with concrete threat models: prompt injection, MCP tool output injection, data exfiltration, privilege separation, runtime policy, audit trails.
