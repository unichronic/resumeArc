## Method Codes

- `Official apply`: use the company job page first.
- `Official + DM`: apply formally, then send a short founder/recruiter/engineering DM.
- `Wellfound + DM`: apply on Wellfound, then DM founder/recruiter because Wellfound applications can be low-signal.
- `LinkedIn post`: comment/DM/apply through the post or linked form.
- `YC apply`: apply via YC account; use the founder-note field carefully.
- `Cold email`: only use when there is no reliable application form.
- `Verify first`: open the link manually before spending time tailoring.

## Best Workflow Per Batch

1. Apply Batch 1 through official forms first.
2. For Wellfound/LinkedIn roles, submit and immediately send a 4-line DM referencing the exact project fit.
3. Do not write fully custom resumes for every Batch 2/3 role until the role is verified live.
4. For YC roles, use the YC note field and keep it project-specific. Do not send separate cold emails unless a founder email is public and appropriate.
5. Keep a tracker column for `submitted`, `follow-up date`, `resume used`, and `reply`.
